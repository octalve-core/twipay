# Legacy ErhaPay UI Inventory

The uploaded ErhaPay frontend is a design/product reference, not the TwiPay architecture. Batch 1 observed these useful product areas: authentication, funding, transfers, static/virtual accounts, transaction history, notifications, referrals, services, settings, cards, flights and hotels.

TwiPay V1 prioritizes identity/security, wallet/ledger, funding/transfers, utilities and **events**. Flights/hotels/cards remain future modules. Legacy localStorage authentication, inherited API URLs, mock balances/accounts and placeholder data must not be copied.

Migration rule: migrate UX intent/components only after reviewing them against TwiPay security, accessibility, responsive design and API contracts.
